# Практическая работа №2: Интерактивная работа с MySQL в Docker (Логирование)

## 🎯 Цель работы
Освоить работу с СУБД MySQL внутри Docker-контейнера, настроить встроенное логирование запросов в системную таблицу, создать представления (VIEW) для фильтрации логов, а также выполнить экспорт базы данных.

## ⚙️ Выполненные шаги
1. Настроен файл `my.cnf` для работы с кириллицей (`utf8mb4`) и логирования в таблицу (`general_log = 1`, `log_output = TABLE`).
2. Запущен Docker-контейнер на базе `mysql:8.0`.
3. Создана база данных `sql_practice`, таблицы `customers` и `orders`.
4. Создано представление (VIEW) `my_actions` для фильтрации системного лога `mysql.general_log`.
5. Таблицы наполнены тестовыми данными (5 клиентов, 6 заказов).
6. Выполнен экспорт лога (`my_actions_export.txt`) и создан чистый дамп базы (`dump_clean.sql`).

## 📁 Описание файлов
* **`my.cnf`** — конфигурация MySQL.
* **`dump_clean.sql`** — дамп базы данных `sql_practice`.
* **`my_actions_export.txt`** — лог действий (SELECT, INSERT), полученный через VIEW.
* **`README.md`** — описание работы.
